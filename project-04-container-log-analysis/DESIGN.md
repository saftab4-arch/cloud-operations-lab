# Container Log Analysis & Incident Reporting Tool

## Objective

Provide automated container troubleshooting and incident reporting.

## Features

- Detect running containers
- Collect container logs
- Detect errors
- Detect warnings
- Assign incident severity
- Generate report file
- Provide troubleshooting recommendations

## Severity Levels

### HIGH

One or more errors detected.

### MEDIUM

Warnings detected but no errors.

### LOW

No errors or warnings detected.

## Report Sections

- Timestamp
- Container Summary
- Container Details
- Log Analysis
- Severity Assessment
- Recommendations
